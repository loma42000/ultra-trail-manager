# Ultra Trail Manager

Jeu de gestion de carrière de traileur (entraînement, staff, sponsors, plan de course, UTMB World Series).

**Jouer :** ouvrir le site GitHub Pages du dépôt, puis dans Edge/Chrome : menu ⋯ → Applications → *Installer Ultra Trail Manager*.

Tout le jeu tient dans `index.html`. Les sauvegardes sont stockées dans le navigateur.
